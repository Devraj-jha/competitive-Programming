| Code pattern           |        Complexity |
| ---------------------- | ----------------: |
| `x++`                  |              O(1) |
| loop `0 → n`           |              O(n) |
| loop `i *= 2`          |          O(log n) |
| loop `i /= 2`          |          O(log n) |
| two sequential n-loops |              O(n) |
| two nested n-loops     |             O(n²) |
| n-loop × log-loop      |        O(n log n) |
| three nested n-loops   |             O(n³) |
| recursion `n → n-1`    |              O(n) |
| recursion `n → n/2`    |          O(log n) |
| two recursive branches | potentially O(2ⁿ) |
