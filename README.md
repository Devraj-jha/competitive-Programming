# Competitive Programming

C++ solutions for data structures, algorithms, and competitive programming problems.

## Structure

```
Data_Structure/     - Arrays, Linked Lists, Trees
Mathematics/        - GCD, LCM, Primes, Modular Arithmetic
sortings/           - Sorting algorithms
Two_pointers/       - Two pointer technique
Common patterns/    - Algorithmic patterns
800-1200/           - Codeforces problems by rating
```

## Compile

```bash
g++ -o output filename.cpp
./output
```

## Topics

- Data Structures: Arrays, Linked Lists, Trees
- Algorithms: Sorting, Two Pointers, GCD/LCM
- OOP Concepts and study notes
