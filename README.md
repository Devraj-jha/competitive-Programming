# Competitive Programming Repository

A comprehensive collection of competitive programming solutions, data structures, algorithms, and study notes in C++.

## 📚 Topics Covered

### Data Structures
- **Arrays** - Basic array operations and problems
- **Linked Lists** - Implementation, traversal, insertion, deletion, and problems
- **Trees** - Tree basics and implementations

### Algorithms
- **Sorting** - Merge sort and other sorting algorithms
- **Two Pointers** - Opposite direction and same direction techniques
- **Mathematics** - GCD, LCM, Modular Arithmetic, Prime Numbers

### Problem Categories
- **Rating 800-1200** - Codeforces-style problems organized by difficulty
- **Common Patterns** - Reusable algorithmic patterns and techniques

### Learning Resources
- **OOP Concepts** - Object-oriented programming fundamentals
- **C++ Notes** - Language-specific notes and implementations
- **Study Materials** - Theory notes and problem-solving strategies

## 🛠️ How to Compile and Run

### Prerequisites
- C++ compiler (g++ recommended)
- Basic understanding of C++ syntax

### Compilation
```bash
# Compile a specific file
g++ -o output filename.cpp

# Example
g++ -o test test.cpp
./test
```

### For linked list implementations
```bash
# Example: Running linked list basics
g++ -o linked_list Data_Structure/Linked_list/basics.cpp
./linked_list
```
